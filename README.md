# isaacyauk_portfolio
Welcome to the repo for my personal portfolio website! I hope you find whatever it is you're looking for here (and that it's well-written... 😅)

# Product Vision
A simplistic yet elegant webpage that gives a lot of succint but good information about who I am, academically, personally, and professionally! Each page is to be highly simplistic, not bombarding the user with too much information, but still have things "layered" so that a site visitor can dig deeper if they want to!
